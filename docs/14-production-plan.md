## Current phase

Design and evaluation. No implementation is authorized. The repository begins
with populated specifications and explicit gaps so later agents do not invent
creative decisions during coding.

## Proposed phase sequence

1. **Complete design:** resolve every blocking item in the design index and
   obtain explicit approval of the implementation-ready specification.
2. **Feasibility and asset research:** inspect historical *Unpaid* prototypes,
   select technical stack, audit reusable assets and licences, test the hardest
   organoid/interaction/rendering assumptions.
3. **Vertical slice:** implement 20–30 minutes with one complete loop and
   evaluate against approved criteria.
4. **Minimum-complete game:** produce a coherent approximately 90-minute
   campaign if the slice passes.
5. **Full target:** deepen systems, content, and branches toward an
   approximately three-hour first playthrough.
6. **Polish and release preparation:** accessibility, performance, scientific
   language, licensing, reproducibility, documentation, and portfolio evidence.
7. **Separate public handoff:** create a GitHub remote, public release, and
   portfolio integration only through later explicit approvals.

## Scope controls

- Compact institute floor instead of open campus.
- Five recurring supporting characters; most institutional roles remain
  remote or environmental.

- Modular epilogues instead of a bespoke cinematic for every state.
- No persistent hands, photorealism, account system, or multiplayer dependency.
- Third-party assets may reduce workload only after licence and style review.
