# Asset Manifest

No production assets have been selected or imported.

Every external or generated asset must be entered here **before** integration.
Public downloadability is not evidence of permission. Verify the exact licence
version, intended public web use, modification rights, redistribution model,
attribution, and compatibility with the project's eventual licensing.

## B08 selection and attribution policy

Use only assets that permit public redistribution in the future GitHub
repository and deployed web game, modification where needed, and clear
attribution. Prefer original work, CC0, CC-BY, OFL, MIT, Apache, or paid assets
with equally clear public redistribution and modification rights. Do not use
non-commercial or no-derivatives assets by default.

Do not select a complete pre-built laboratory scene, an unmodified character
pack, real university, journal, company, or game branding, real people's
likenesses or voices, private source material, or an asset with unclear
redistribution terms. Recreate or exclude an unsuitable asset. The public
repository and the in-game Credits/Licences page must provide the required
attribution.

For each generated asset, record the tool or service, date, source inputs,
human changes, relevant terms or licence status, and any uncertainty. For an
original asset, record its creator and the intended public-release licence
decision when that decision is made. This policy does not select a repository
licence or create a production asset.

## Required record fields

Before integration, each row must state the asset identifier, files, purpose,

redistribution conditions, and verification date/status. Add generated-tool
and provenance information in the row or a linked note. Do not use a placeholder
row as evidence that a real asset passed review.

## Generated or original assets

Record original and generated assets too. For generated work, retain the tool,
model/service, date, relevant terms, source inputs, human modifications, and
any uncertainty about public release. Do not place credentials, private source
material, or unverifiable ownership claims in this manifest.
